## 🎯 核心功能说明

### AI自主画图工作原理

1. **管理员配置**
   - 在预设中勾选"🎨 AI自主画图"
   - 填写画图引导语（可选）

2. **系统提示词注入**
   ```
   ...（原有系统提示词）...
   
   【画图标记速查】用下面的标记来画画，必须另起一行单独输出：
   · 画你自己（雪年）  →  [DRAW:ref=xn]场景动作描述（50字内）[/DRAW]
   · 参考用户发的图来画  →  [DRAW:ref=img]场景动作描述[/DRAW]
   · 两者都要          →  [DRAW:ref=all]场景动作描述[/DRAW]
   · 普通画图          →  [DRAW]场景动作描述[/DRAW]
   ...
   
   【画图风格引导】你擅长创作精美的二次元插画。当对话涉及场景描述、
   人物动作时，可以主动配图。画图风格：细腻的线条、明亮的色彩。
   ```

3. **AI对话中自主判断**
   - AI根据对话情境判断何时需要配图
   - 输出`[DRAW]`标记触发画图

4. **系统自动处理**
   - 提取`[DRAW]`标记内容
   - 调用画图API生成图片
   - 插入到对话中
   - 从显示文本中移除标记

## 📖 使用指南

### 管理员配置步骤

#### 1. 配置AI自主画图
```
管理后台 → AI设置 → 预设管理 → 展开预设
→ 勾选"🎨 AI自主画图"
→ 填写"AI画图引导语"（可选）
→ 保存设置
```

**引导语示例**：
```
你是一位专业的插画师。当对话涉及以下情况时可以配图：
1. 描述场景、人物动作、表情
2. 讲故事需要氛围渲染
3. 用户明确要求看图

画图风格：二次元动漫风格，明亮色彩，注重细节和表情。
画面构成：优先人物特写，其次场景氛围图。
```

#### 2. 查看对话历史
```
管理后台 → 聊天管理 → 点击"查看"
→ 可看到文本和图片消息
→ 包括用户已删除的对话
```

#### 3. 手动清理对话
```
管理后台 → 聊天管理 → 点击"删除"
→ 确认后永久删除该用户的所有对话
```

## 🆚 对比说明

### AI自主画图 vs 手动画图模式

| 特性 | AI自主画图 | 手动画图模式 |
|------|-----------|------------|
| **触发方式** | AI在对话中自主判断 | 用户手动点击画图按钮 |
| **控制者** | AI决定何时画、画什么 | 用户输入画面描述 |
| **配置位置** | 预设级别开关 | 全局画图配置 |
| **系统提示词** | 注入画图标记协议 | 不注入 |
| **适用场景** | 增强互动性，让AI更智能 | 用户明确想要生成图片 |
